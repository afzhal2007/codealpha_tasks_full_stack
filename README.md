# Social Wave - Mini Social Media Platform

Social Wave is a premium full-stack mini social media web application built for internship/project submission.

## Features

- User registration and login
- User profile with name, bio and avatar URL
- Create and delete posts
- Like and unlike posts
- Add comments to posts
- Follow and unfollow users
- Explore people page
- User profile page with posts
- SQLite database for users, posts, comments, likes and followers
- Premium dark responsive UI

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite
- Auth: Express Session + bcrypt password hashing

## How to Run

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```
