# E Web - Simple E-commerce Store

Premium dark e-commerce full-stack project using HTML, CSS, JavaScript, Express.js and SQLite.

## Features

- User registration and login
- Product listings
- Product details page
- Shopping cart
- Quantity update and remove from cart
- Order processing / checkout
- Orders stored in SQLite database
- Premium responsive UI

## Run Project

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Default Products

The database auto-creates and inserts products on first run.
